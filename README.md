1. **给 AI 助手（WorkBuddy 等）检索用的 Skill** —— 你问达芬奇操作问题，AI 先检索这份资料、在对话框里直接中文回答，需要时再调出可视化界面。

## 一、功能一览

整个 skill 的核心是一个**单文件网页浏览器**（`references/手册浏览器.html`，离线自包含），内含四个标签页：

| 标签页 | 内容 | 数据量 | 适合解决 |
|--------|------|--------|----------|
| ⌨ **快捷键速查** | 按模块分组的快捷键，支持关键词搜索 + 模块筛选 | 818 条 / 14 模块 | "分割素材快捷键？" "场景切割怎么触发？" |
| ⚡ **高频速查** | 最常用操作的速查卡，**Mac / Win 双列对照**，按 6 大类分组（播放导航 / 选择工具 / 剪辑修剪 / 入出点转场 / 标记源素材 / 调色页面） | 42 条 / 6 类 | "最常用的是哪几个键？" "Win 上分割是什么？" |
| 🔍 **功能检索** | 21.1 官方手册**全文搜索**（4351 页），命中可阅读整页原文 | 4351 页 | "多机位怎么剪？" "Magic Mask 在哪？" "IntelliScript 怎么用？" |
| 🧩 **内置插件中英对比** | Resolve FX 特效 + Fairlight 音频插件中英对照，含「是否 Studio 专属」标记 | 109 条（FX 77 + Fairlight 32） | "Color Space Transform 中文叫什么？" "降噪是免费还是 Studio？" |

> 说明：四个功能的数据全部**内联**进 `手册浏览器.html` 一个文件里，所以离线、双击即用，不依赖任何外部文件或网络。纯文本检索源（`shortcuts.md` / 两份对照表）也单独放在 `references/`，方便 AI 直接 Grep。

## 二、安装方式

### 2.1 作为 AI Skill 安装（适用于所有支持 Skill 的 Agent）

本 skill 使用**通用的 `SKILL.md` 约定**（YAML frontmatter 含 `name` / `description` / `agent_created: true`），**不限定任何单一客户端**，可安装到任意支持 Skill 机制的 AI 编码 / 对话 Agent（WorkBuddy、Claude Code、CodeBuddy、Cursor、Cline 等）。

**核心步骤**：把整个仓库目录，放进你所用 Agent 的「skills 目录」即可。推荐放在**用户级**目录（跨项目、跨对话生效）。

各常见 Agent 的 skills 目录示例：

| Agent | 用户级 skills 目录 |
|-------|-------------------|
| WorkBuddy | `~/.workbuddy/skills/` |
| Claude Code | `~/.claude/skills/` |
| OpenAI Codex | `~/.codex/skills/`（以客户端实际为准） |
| CodeBuddy | `~/.codebuddy/skills/`（以客户端实际为准） |
| Cursor | `~/.cursor/skills/` 或项目内 `.cursor/skills/` |
| Cline | `~/.cline/skills/` |

> 若你的 Agent 文档约定的是其它路径（如项目级 `.agents/skills/`、`.claude/skills/`），以它的说明为准。本质就是「让 Agent 能扫描到本目录下的 `SKILL.md`」。只要 Agent 支持按 `description` 里的触发词自动加载 skill，本 skill 即可生效。

**安装命令（以 WorkBuddy 为例，其余把路径换成上表对应目录即可）**：

```bash
# 方式一：git clone（推荐，方便后续更新）
git clone https://github.com/akahoz94/davinci-21-chinese-manual.git \
  "$HOME/.workbuddy/skills/达芬奇21中文操作手册"

# 方式二：下载 ZIP 后解压 / 直接复制目录
cp -r davinci-21-chinese-manual "$HOME/.workbuddy/skills/达芬奇21中文操作手册"
```

- `$HOME` 在 Windows 上通常是 `C:\Users\你的用户名`。
- 放入后**重启对应客户端 / 开一个新对话**，提到达芬奇相关问题时本 skill 会被自动加载（前提是 Agent 支持按 `description` 触发词自动调用 skill）。

### 2.2 仅作为网页使用（不需要 AI）

如果你**只想要那本可搜索的中文手册网页**，不需要 AI：

1. 下载本仓库的 `references/手册浏览器.html`（单文件，约 7–8 MB）。
2. 用任意现代浏览器（Chrome / Edge / Firefox / Safari）**双击打开**。
3. 全部数据已内联，**离线可用**，可随意复制、发给同事、放到 U 盘。

## 三、作为 AI Skill 怎么用

这是本项目设计的**主交互方式**。当你问 AI 关于达芬奇的**操作类问题**时：

1. **自动加载**：你提到达芬奇（DaVinci Resolve）的任何操作、功能位置、菜单路径、快捷键、工作流、某面板/工具怎么用、内置插件中英文名等，AI 会**优先加载本 skill** 进行检索（旧版「达芬奇中文操作手册」skill 仅作为深度补充归档，不会优先调用）。
2. **对话框直接回答**：AI 检索本 skill 的资料后，**直接在对话框用中文给你答案**——给结论 + 操作步骤 1/2/3 + 高亮的快捷键，**不会只甩链接或只说"去查"**。
3. **答完给选项**：每次回答后，AI 会主动给出 2–4 个可继续操作的选项（例如「① 打开可视化浏览器自查 ② 查某快捷键 ③ 看某插件中英对照 ④ 深查 21.1 原文」）。
4. **按需调出界面**：只有你选择「查快捷键 / 看插件对照 / 自己浏览」时，AI 才会调出 `手册浏览器.html` 的可视化界面。**不会一上来就弹浏览器**。

**示例对话**

```
你：多机位剪辑怎么用？
AI：（先检索 skill，对话框回答）
    多机位剪辑在「多机位」页面 / 剪辑页面的多机位菜单下：
    1. 把多台机位的素材选中，右键 → 使用所有素材创建多机位剪辑…
    2. 双击打开多机位时间线，播放时按数字键 1/2/3… 实时切换机位
    3. 用 PerformMulticamSmartSwitch 可让 AI 自动切换（Studio 专属）
    快捷键：进去多机位查看器 = ⌘+[ / Ctrl+[ …
    —— 想进一步看？① 打开可视化浏览器自查 ② 查多机位相关快捷键 ③ 看其它
你：①
AI：（调出 手册浏览器.html，定位到「功能检索」tab）
```

## 四、可视化浏览器使用详解

打开 `references/手册浏览器.html` 后，顶部有四个标签页，深色主题、顶部带搜索框。

### 4.1 ⌨ 快捷键速查

- **布局**：按 14 个模块分组（媒体 / 快编 / 剪辑 / 剪辑效果与转场 / 套底 / Fusion / 调色 / Fairlight / 交付 / 照片 / 多机位 / 字幕 / 偏好 / 通用等）。
- **搜索**：顶部搜索框输入关键词（中文功能名或英文命令名都行），实时过滤。
- **模块筛选**：可在下拉 / 标签里只显示某个模块，缩小范围。
- **平台切换**：快捷键以 macOS 惯例（⌘ Command / ⌥ Option）展示；Windows / Linux 对应为 `Ctrl` 替 `⌘`、`Alt` 替 `⌥`。页面内通常会同时显示两种写法或给出换算提示。
- 共 **818 条**快捷键。

### 4.2 ⚡ 高频速查（Mac ↔ Win）

- **定位**：从 818 条全表中挑出的**最常用 42 条**，按 6 大类分组：
  一、播放与导航（8）· 二、选择工具（剪辑页面）（9）· 三、剪辑与修剪（11）·
  四、入出点与转场（4）· 五、标记与源素材（4）· 六、调色与页面速记（6）。
- **形态**：表格四列 —— **操作 / Mac / Win / 说明**，按键渲染成键帽样式。
- **为什么有它**：全表 818 条适合精确查找，但"刚上手该记哪几个"需要一张小而精的卡。
- **交互**：顶部搜索框实时过滤（搜操作名或按键名均可），另有分类下拉可只看某一类。
- 想查全量请回到「⌨ 快捷键速查」tab（818 条）。

### 4.3 🔍 功能检索（21.1 全文）

- **数据**：DaVinci Resolve 21.1 官方参考手册全文 **4351 页**，已内联。
- **搜索**：输入任意中文 / 英文关键词，全手册检索；结果列出命中的页码与片段。
- **阅读整页**：点击某条结果，可阅读该页的完整原文（含配文），适合「想看手册到底怎么写的」。
- **适合**：某个功能 / 面板 / 工作流到底在哪、怎么用、参数怎么设。

### 4.4 🧩 内置插件中英对比

- **内容**：
  - **Resolve FX 特效**：77 条 / 13 类（调色、模糊、变形、风格化、Resolve FX 等），含中文名、英文名、分类、**是否 Studio 专属**标记。
  - **Fairlight 音频插件**：32 条 / 12 类（均衡、动态、混响、降噪、测量等），含中文名、英文名、**是否 Studio 专属**标记。
  - 合计 **109 条**。
- **用途**：当你在英文界面 / 教程里看到某个效果名，想知道中文叫什么、属于哪类、要不要 Studio 版；或反过来中文名查英文。
- **示例**：`Color Space Transform` → 中文「色彩空间转换」，属「调色」类；`Denoise`（降噪）→ 标注是否为 Studio 专属。

## 五、快捷键平台差异说明

官方手册以 **macOS 惯例**记录快捷键：

| macOS | Windows / Linux |
|-------|-----------------|
| ⌘ Command | Ctrl |
| ⌥ Option | Alt |
| ⌃ Control | Ctrl（部分场景） |
| ⌫ Delete（向前删） | Backspace |

检索 / 回答时，AI 会**同时给出 Mac 与 Win 写法**（例如 `Command+\` / `Ctrl+\`）。若你的系统有出入，以软件内「快捷编辑器 / 帮助」为准。

## 八、常见问题（FAQ）

**Q1：这跟官方手册有什么区别？**
A：内容就是官方 21.1 手册的中文版，信息一致、权威；本仓库额外提供了**可搜索 / 可检索**的形态（网页全文检索 + AI skill），并整理了快捷键表与插件中英对照，方便快速查。

**Q2：为什么打开 HTML 有时稍慢？**
A：因为是单文件内联了 4351 页手册全文（约 7–8 MB），首次加载需解析数据，属正常。之后浏览流畅。

**Q3：快捷键和我的版本不一样？**
A：快捷键跨版本基本通用；本手册基于 21.1。如与你的具体版本有出入，以软件内「快捷编辑器 / 帮助」为准。

**Q4：没有 WorkBuddy 能用吗？**
A：能。直接双击 `references/手册浏览器.html` 即可，离线、无需 AI。

**Q5：AI 没自动加载这个 skill？**
A：确认目录名是 `达芬奇21中文操作手册`、放在**你所用 Agent 的 skills 目录**下（见上文 2.1 表格）；然后**重启客户端 / 开新对话**。触发词包含「达芬奇 / DaVinci Resolve / 快捷键 / 调色 / 多机位 / 插件 / 功能位置」等操作类关键词；同时确认你的 Agent 支持按 `SKILL.md` 的 `description` 自动触发 skill。

**Q6：数据会更新吗？**
A：会随官方手册版本推进更新。关注 GitHub 仓库的 Release / 提交记录；用 `git pull` 即可更新本地 skill。
