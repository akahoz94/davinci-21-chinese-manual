# 问答样例集（回归测试 + 效果展示）

> 用途：① 验证 skill 改动后回答质量没退化；② 给新用户看"它能答成什么样"。
> 路由标注说明：**命中**= 走结构化速查数据直接答；**索引**= 查 `index.json` 定位页码后精读；**开发**= 走官方开发文档。

---

## 一、普通操作（极速 · 高频速查命中）

**Q1：达芬奇怎么变速？**
- 路由：命中 → 高频速查 tab（三、剪辑与修剪 / 变速工具）
- 期望答案要点：选中片段 → `Command+R`（Win `Ctrl+R`）打开变速工具 → 设速度百分比或时长 → 精细曲线用 **Retime Curve**（Retime Speed 拖线段 / Retime Frame 可倒放）。一句话给完，末行必问是否开浏览器。

**Q2：怎么重置某个调色节点的参数？**
- 路由：命中 → 高频速查 tab（八、调色：节点与静帧）
- 期望答案要点：节点编辑器右键 → 「重置节点」/ 检查器右上角重置；快捷键 `Command+P`（Win `Ctrl+P`）旁路、`Command+L`（Win `Ctrl+L`）锁定防误改。

**Q3：怎么删除时间线里的空隙？**
- 路由：命中 → 高频速查 tab（13 类 · 三、剪辑与修剪）
- 期望答案要点：菜单「编辑 > 删除间隙」；单个间隙可用波纹删除 `Delete`（Mac ⌦）。

## 二、快捷键（极速 · 快捷键 tab 命中）

**Q4：分割片段的快捷键是什么？**
- 路由：命中 → 快捷键 tab（`shortcuts.md`）
- 期望答案要点：`Command+\`（Mac）/ `Ctrl+\`（Win），在播放头处分割所有启用自动选择轨道的片段；刀片工具 `B` 手动点击切。

**Q5：Win 上全屏检视器按什么？**
- 路由：命中 → 高频速查 tab（一、播放与导航）
- 期望答案要点：`Shift+F`；影院模式 `Ctrl+F`、增强模式检视器 `Alt+F`（Mac 为 Command / Option）。

**Q6：Color Space Transform 中文叫什么？是不是 Studio 专属？**

**Q7：降噪在免费版能用吗？**

## 四、功能 / 面板定位（索引 → 精读）

**Q8：Magic Mask 在哪里，怎么用？**
- 路由：未命中速查 → `Grep index.json` 命中页码（P3663 / P3675 等）→ 精读 `21.1原文检索.txt` 局部 ±30 行
- 期望答案要点：调色页面 → 特效库 / Neural Engine → Magic Mask；说明**仅 Studio**；给 1/2/3 步骤；可标注「见第 X 章 P3663」。

**Q9：多机位剪辑怎么操作？**
- 路由：索引命中 P1035–1042 → 精读
- 期望答案要点：素材箱选中多个片段右键「新建多机位片段」→ 同步方式（时间码 / 波形 / 入点）→ 时间线切角（多机位查看器）。

**Q10：IntelliScript 怎么用？**
- 路由：索引 → 精读；若手册未覆盖则明说"手册未覆盖"并联网补充
- 期望答案要点：给出官方逻辑步骤，不编造。

## 五、开发 / API / MCP（官方开发文档 tab）

**Q11：怎么用 Python 新建一个项目并导入素材？**
- 路由：开发 → `官方开发文档蒸馏.md`
- 期望答案要点：先开「Preferences → System → General → External scripting = Local」；`sys.path` 加 Modules 目录；`bmd.scriptapp("Resolve")` → `GetProjectManager().CreateProject(name, path)` → `GetMediaPool().ImportMedia([{"FilePath": ...}])`；提示 64 位 Python。

**Q12：TimelineItem 怎么改片段速度？**
- 路由：开发 → 官方开发文档（TimelineItem 93 个方法）
- 期望答案要点：给出真实方法签名（如 `SetClipProperty(propertyName, propertyValue)`，属性值为**字符串**），并提醒返回值要判 bool。

**Q13：SetLUT 的 nodeIndex 是从 0 还是 1 开始？**
- 路由：开发 → 官方文档踩坑清单第 1 条
- 期望答案要点：**1-based**（v16.2 起），`1 ≤ nodeIndex ≤ 节点总数`，传 0 会失败。

**Q14：MCP 怎么接达芬奇？**
- 路由：开发 → `官方开发文档蒸馏.md` 第 7 节 + `mcp-接入示例.md`
- 期望答案要点：把 Scripting API 包成 MCP tool，保持长驻连接、失败自动重连、危险操作二次确认、返回结构化 JSON（ok/message/data）。

## 六、非极速模式（深度解读 · 触发式）

**Q15（追问 2 轮后）：详细讲讲达芬奇的色彩管理（ACES / RCM）该怎么选？**
- 路由：触发非极速 → `index.json` 定位（色彩管理章节 P219 / HDR P252）→ 全文深度精读 ±50~100 行 → **联网搜索双重比对** → 给最精确解读
