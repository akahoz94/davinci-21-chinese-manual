# 口语问句 → 检索词 映射层（解决"动词短语"Grep 落空）
# 原理：用户打「怎么调色」「加字幕」「导出」，但资产里是名词「调色」「字幕」「Deliver」。
#      agent 先 Grep 本表拿到核心名词，再用名词去查各资产。
# 用法：把用户问句里的口语片段剥掉，只留名词/动词核心词，再逐个 Grep 本表。
# 格式：口语说法⇥核心检索词
