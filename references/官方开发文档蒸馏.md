## 2. Scripting API 蒸馏（最常用，MCP 控制的核心）

### 2.1 入口与连接

- 语言：Lua 5.1 或 Python ≥ 3.6（Resolve 21.1 自带定制 Python 3.14，已可直接 `import DaVinciResolveScript`）。
- 获取 `resolve` 对象（脚本内已预定义；外部脚本需主动取得）：
  ```python
  import DaVinciResolveScript as dvr_script
  resolve = dvr_script.scriptapp("Resolve")
  ```
- 运行方式：① 内部（Workspace > Console / Scripts 菜单 / Deliver 渲染前后脚本）；② 本地终端；③ 局域网（需开启 External scripting = Local/Network，Studio 专属，端口 1144）。
- 无界面模式：命令行 `-nogui` 启动，脚本 API 仍可用。
- 外部 Python 需设环境变量：`RESOLVE_SCRIPT_API`、`RESOLVE_SCRIPT_LIB`、`PYTHONPATH`（见 README，Windows 下 `fusionscript.dll` 在程序目录）。

### 2.4 关键约定（易踩坑）

- **设置是 key-value 字典**：`Project.GetSettings()/SetSettings(dict)`、`Timeline.GetSettings()/SetSettings(dict)`、`MediaPoolItem.GetClipProperty()/SetClipProperty(name,value)` 均与 UI 参数名一一对应；改前在 UI 设一次、对照快照即可知道 key。
- `Timeline.SetSettings` 除 `useCustomSettings` 外，仅当其 = `'1'` 时其它项才能改；`useCustomSettings` 永远先应用。
- **弃用 API**（见 README）：旧的 `GetSetting(name)` 改用 `GetSettings()` 取 dict；`AppendToTimeline(clips)` 改用 `AppendToTimeline([AppendClipInfo])`；`AddItemListToMediaPool` 改用 `AddItemListToMediaPool([MediaStorageItemInfo])`；`SetMetadata(k,v)` 改用 `SetMetadata({k:v})`。渲染用 jobId 字符串而非索引（`StartRendering([jobIds])`）。
- **Studio / AI 专有**：Free 版调用 Studio 函数返回 False；`GenerateSpeech`、`AnalyzeForSlate`、`AnalyzeForIntellisearch(better)`、`Transcription` 扩展语言模型等需先装对应 Extras（Extras Download Manager）。
- 导出 `Timeline.Export`：`EXPORT_AAF/EXPORT_EDL` 需要 `exportSubtype`（如 `EXPORT_AAF_NEW/EXISTING`、`EXPORT_CDL/SDL/...`）；18.1 起 FCPXML 1.3–1.7 已不支持。
- 多返回的 list/dict 结构：Lua 无 list/dict，用带索引的 table 表达。

### 2.5 最小示例

```python
import DaVinciResolveScript as dvr
resolve = dvr.scriptapp("Resolve")
pm = resolve.GetProjectManager()
proj = pm.LoadProject("MyProject") or pm.CreateProject("MyProject")
mp = proj.GetMediaPool()
folder = mp.GetRootFolder()
clips = mp.ImportMedia([{"FilePath": r"D:\footage\clip.mov"}])
mp.AppendToTimeline([{"mediaPoolItem": clips[0]}])
```

## 3. Workflow Integration 蒸馏（Studio 专属）

- 形态：Electron 应用（`.node` 模块 `WorkflowIntegration.node`）或 Python/Lua 脚本（带 UIManager UI），从 `Workspace → Workflow Integrations` 加载。
- JS 入口：`require('./WorkflowIntegration.node')` → `Initialize(pluginId)` → `GetResolve()` 拿到与脚本 API 相同的 `resolve` 对象。
- `WorkflowIntegration` 模块 API：`GetInfo / Initialize / InitializePromise / GetResolve / GetResolvePromise / RegisterCallback(name, fn) / DeregisterCallback / CleanUp / SetAPITimeout(secs)`。
- 回调：`RenderStart` / `RenderStop` / `ResolveQuit`。
- 目录位置：Win `%PROGRAMDATA%\Blackmagic Design\DaVinci Resolve\Support\Workflow Integration Plugins\`；结构 `com.<company>.<plugin>/`（package.js / main.js / index.html / manifest.xml）。
- v19.0.2 起 Electron 默认启用 sandbox + context isolation，旧插件需审计（参考 `CompatibleSamplePlugin`）。
- UIManager（Qt 封装）：`ui.UIManager()` + `bmd.UIDispatcher(ui)`；`AddWindow/AddDialog` + `RunLoop/ExitLoop`；元素 Label/Button/CheckBox/ComboBox/SpinBox/Slider/LineEdit/TextEdit/ColorPicker/Tree/TabBar，布局用 `HGroup/VGroup`，事件挂在 `win.On.<ID>.<Event>`。
- 插件脚本被加载时自动注入 `resolve` 与 `project` 变量。

## 4. 技术文档蒸馏

### 4.1 DaVinci Remote Panel（远程调色台）
- 角色：用户机（连 USB 面板）经网络控制远程的调色机（运行 Resolve）。
- 要求：两机网络互通；用户机开放 **端口 20323** 入站；两机版本一致。
- 配置：调色机高级偏好加 `Local.Panel.Remote.Address = <用户机IP>:20323`，改后退出 Resolve；用户机先启动 `DaVinciRemotePanel.bat`（Advanced Panel 用 `DaVinciRemoteAdvPanel.bat`），再在调色机启动 Resolve。
- 路径：Win `%ProgramFiles%\Blackmagic Design\DaVinci Resolve\DaVinciRemotePanel.bat`。

### 4.2 用户配置目录与自定义（DR16 起）
- 配置/预设/偏好改到**每用户**目录，多用户更安全；系统级旧文件保留不动。
- 覆盖环境变量（安装后、首次启动前设）：`BMD_RESOLVE_SUPPORT_DIR`（应用支持）、`BMD_RESOLVE_CONFIG_DIR`（配置）、`BMD_RESOLVE_LOGS_DIR`（日志）、`BMD_RESOLVE_LUT_DIR`（LUT，需所有用户可访问）、`BMD_RESOLVE_LICENSE_DIR`（授权）。
- Win 新默认：`%APPDATA%\Blackmagic Design\DaVinci Resolve\Support`（应用支持）与 `...\Preferences`（配置）；旧默认在 `%PROGRAMDATA%\Blackmagic Design\DaVinci Resolve\Support`。
