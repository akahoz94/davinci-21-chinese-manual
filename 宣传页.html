  • 官方开发文档 16KB → 121KB：人工蒸馏实战要点（接入 / 对象模型 / 10 组任务代码 / 15 条踩坑 / MCP 要点）+ 从官方 .pyi 自动提取的完整 API 参考（62 类 / 410 方法 / TypedDict 字段 / 41 组常量）。

  • 版本差异提示：用户使用 20/19/18 等旧版本时先提示差异，不拿 21.1 硬套。

  • 非极速触发式：仅当用户明确要深度对话或同一问题多次追问(≥2 轮)才触发，改走全文检索深度精读 + 联网搜索双重比对。
